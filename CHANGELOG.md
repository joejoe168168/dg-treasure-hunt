# Changelog

## 1.2.0 — Development candidate

- Balanced Practice mode now gives one Maths, one English and one Chinese question per chest.
- Added a real ten-minute Quick Hunt timer and time-up result.
- Added mastery-aware question selection and stable question IDs with migration.
- Added accessible dialog semantics, focus management, announcements and non-colour answer feedback.
- Added spatial collision indexing.
- Added a privacy-safe learning-progress summary and local-only leaderboard preference.
- Hardened leaderboard rendering and server validation.

Known limitations: the production bundle still reports a large Three.js chunk; human visual approval, real curriculum reviewer sign-off, public-deployment rate limiting and concurrency-safe leaderboard storage remain open.
